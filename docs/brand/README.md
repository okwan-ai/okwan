# Okwan logo

The original mark (§2.2, §9 2026-11-06): two strokes for the systems, the
yellow signal dot for where they disagree, and "okwan" in Instrument Sans
SemiBold. The word is outlines, so the files need no font.

| File | Use |
|---|---|
| `okwan-logo.svg` | Wordmark on light grounds (ink `#0A0A0A`) |
| `okwan-logo-light.svg` | Wordmark on dark grounds (white) |
| `okwan-logo-stacked.svg` | Mark over word, on night, for avatars and social cards |
| `okwan-icon.svg` | The mark on a night tile: favicon, app icon |

Signal yellow is `#FFD400` and means one thing: where two systems disagree.
